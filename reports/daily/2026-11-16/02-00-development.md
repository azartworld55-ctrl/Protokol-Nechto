## Что реально реализовано

- Добавлен отдельный проект `Protocol.ProfessionConfig`.
- Добавлена модель квоты с обязательным непустым ID профессии и положительным количеством.
- Конфигурация принимает только уникальные ID профессий и только тогда, когда сумма квот равна ровно 12.
- Добавлен строгий JSON-документ версии 1 и JSON Schema. Неизвестные поля, повторяющиеся поля и неподдерживаемые версии отклоняются.
- Добавлен детерминированный распределитель: Fisher–Yates с собственным SplitMix64 PRNG и устранением modulo bias. Один seed и один порядок конфигурации дают одну и ту же последовательность на поддерживаемых .NET runtime.
- Добавлен отдельный smoke-test проект с проверками суммы, дубликатов, пустых/отрицательных значений, JSON round-trip, неизвестных полей/версий и фиксированной последовательности seed 417.
- Добавлен отдельный GitHub Actions workflow для сборки и тестов.
- README, план и архитектура дополнены ссылкой и статусом нового модуля.

## Архитектурные решения и ограничения

- Значений квот по умолчанию нет. Синтетические числа в тесте — только тестовая фикстура, не игровой баланс.
- Модуль пока не подключён к `StationRosterGenerator` из PR #1. Это отдельная ветка от актуального main, поэтому код PR #1 не копировался и не переписывался.
- Модуль распределяет только идентификаторы профессий; навыки, рабочие места и смены остаются за другими системами.
- Не использованы RimWorld, Verse, Unity, Harmony или Ports1de API. Это независимая логика.
- `net10.0` используется для CI-сборки, а не как подтверждение runtime Ports1de. Точный runtime и DLL всё ещё не подтверждены.
- Mobile-first UI в этом обновлении не добавлялся: UI API порта не подтверждён, поэтому нельзя честно заявлять о готовом сенсорном интерфейсе.

## Источники и лицензии

Весь новый исходный код написан для этого репозитория. Сторонний код, ассеты и DLL не копировались. Использованы только стандартные библиотеки .NET, включая `System.Text.Json`; сторонние NuGet-пакеты не добавлялись.
