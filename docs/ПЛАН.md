## Личный список заданий игрока

Каждое задание игрока хранится отдельно от поручений NPC. В игровом HUD оно должно отображаться в постоянно доступной компактной панели «МОИ ЗАДАНИЯ» с приоритетом и описанием; завершённые задания убираются из активного списка, но остаются в истории. В ядре уже есть `PlayerTaskBoard` и `PlayerTaskHudSnapshot`; отрисовка панели зависит от ещё не подтверждённого UI API Ports1de.

## Правило разработки

Каждый этап должен иметь маленький проверяемый результат. Не переносить в проект код стороннего мода только потому, что он работает на ПК: сначала проверять лицензию, API и Android-совместимость. Все пользовательские интерфейсы проектировать с приоритетом сенсорного управления Ports1de.


## Ограничения нового этапа

Решения паразита и реакции подозрения реализованы в независимом ядре и покрыты smoke-тестами. Они не управляют пешками напрямую: игровой адаптер обязан формировать честный список видимых кандидатов, число присутствующих жителей и оценку риска из данных карты. NPC реагируют только на записи в собственном журнале; автоматическое распространение подозрений по всей станции запрещено.
