# План разработки

Статус: предварительный план. Целевая платформа — **RimWorld Android 1.7 через Ports1de**. Совместимость не считается подтверждённой до проверки на точной сборке и устройстве.

## Этап 0 — техническая разведка Ports1de

- [ ] Уточнить точную версию установленной сборки Ports1de.
- [ ] Получить доступные исходники/документацию порта и выяснить загрузчик модов.
- [ ] Проверить версии .NET/Mono, Harmony и доступность нужных игровых API.
- [ ] Определить ограничения Android: файловая система, производительность, память, сенсорный ввод и масштаб UI.
- [ ] Проверить лицензии и происхождение кандидатов на повторное использование.
- [ ] Собрать минимальный тестовый мод и проверить его загрузку в Ports1de.

## Этап 1 — минимальный каркас

- [ ] Создать структуру RimWorld-мода (About.xml, Defs, Assemblies и исходный проект — после подтверждения целевой сборки).
- [ ] Проверить, что мод обнаруживается и загружается на устройстве.
- [ ] Добавить безопасное логирование и переключатель отладки.
- [ ] Зафиксировать инструкцию установки и тестирования.

## Этап 2 — управление и камера

- [ ] Прототип выбора одного персонажа.
- [ ] Камера следует за выбранным персонажем.
- [ ] Проверить удобство прямого управления на сенсорном экране.
- [ ] Интерфейс проектировать под касания пальцами, не под геймпад.
- [ ] Не менять стандартное управление Ports1de до подтверждения работоспособности прототипа.

## Этап 3 — обзор и карта

- [ ] Ограничить видимость обзором персонажа и препятствиями.
- [ ] Разделить известную планировку и актуальную видимую информацию.
- [ ] Убедиться, что невидимые NPC продолжают симуляцию без раскрытия их действий игроку.

## Этап 4 — жители и социальная симуляция

- [x] Генерация ровно 12 жителей с уникальными ID/именами, возрастом, личностью, привычками и особенностями.
- [x] Независимая JSON-конфигурация квот профессий и детерминированное распределение ровно 12 назначений; реальные значения квот остаются решением игрового баланса.
- [x] `ProfessionRosterComposer` подключён непосредственно к `StationRosterGenerator`.
- [x] Генератор использует общий детерминированный SplitMix64 без `System.Random`; полный снимок воспроизводится при фиксированном seed.
- [x] Симметричные отношения с отдельными шкалами доверия и знакомства.
- [x] Личная память с проверкой владельца, дедупликацией событий и неизменяемыми снимками.
- [x] Передача слухов только через явное событие разговора, с затуханием достоверности и сохранением происхождения.
- [x] `Protocol.Core` и `Protocol.Social` соединены через `StationSocialState` и стабильное отображение Guid → `ResidentId`.
- [x] Сквозные тесты полного ростера из 12 жителей, изоляции памяти и цепочки пересказов.
- [ ] Расписания, потребности и автономная работа NPC.
- [ ] Диалоги, забывание, переоценка воспоминаний и конфликты.

## Этап 5 — паразит

- [ ] Ровно один паразит на партию.
- [ ] Самостоятельное наблюдение и выбор цели только на основе доступной ему информации.
- [ ] Ограничение нападения ситуацией без свидетелей.
- [ ] Полное копирование внешности, имени и социальной роли.
- [ ] Перенос воспоминаний жертвы без доступа к неизвестной ей информации.
- [ ] Отсутствие всеведения и использование только полученной информации.

## Этап 6 — расследование и последствия

- [ ] Система наблюдений и подозрений без безошибочного индикатора.
- [ ] Обвинения и социальные последствия.
- [ ] Арест за преступления против невиновных.
- [ ] Возможность побега из-под стражи.
- [ ] Продолжение игры за другого живого персонажа после гибели игрока.

## Этап 7 — сценарий и полировка

- [ ] Большая готовая база с функциональными помещениями.
- [ ] Бытовые и природные опасности.
- [ ] Несколько концовок без фиксированного лимита дней.
- [ ] Профилирование производительности и тестирование длительных партий на Android.

## Правило разработки

Каждый этап должен иметь небольшой проверяемый результат. Не переносить сторонний код без установленного источника и совместимой лицензии. Не подключать неподтверждённые API Ports1de. Все игровые интерфейсы проектировать mobile-first и под сенсорное управление.
