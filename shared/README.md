# AzartWorld.Core

Здесь будет размещаться общий код, используемый несколькими модами AzartWorld.

## Правило выделения общего кода

Не переносить сюда код только ради абстракции. Компонент становится частью Core, когда:
- он нужен как минимум двум модам;
- его интерфейс стабилен;
- он не содержит правил конкретного игрового проекта.

## Планируемые области

- общая конфигурация и настройки;
- диагностика и журналирование;
- общие утилиты;
- общие адаптеры Ports1de, если они применимы ко всем модам;
- общие вспомогательные механизмы сохранения, только если они действительно повторяются.

## Ограничения

- Core не должен содержать механику тюремной симуляции или «ПРОТОКОЛА: НЕЧТО».
- Не добавлять зависимость от Harmony или сторонних DLL до проверки загрузчика Ports1de.
- Не считать API доступным, пока он не проверен на целевой сборке.
- Если общий код создаёт проблемы совместимости, отдельный мод должен иметь возможность работать без него.

## Текущий статус

Пока это архитектурная точка назначения, а не готовая DLL. Первым потребителем станет Prison Colony; фактический состав библиотеки определится по мере появления повторно используемого кода.
