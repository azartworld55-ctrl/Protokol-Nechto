# ПРОТОКОЛ: НЕЧТО

Модификация для **RimWorld 1.7 Android (порт Ports1de)**: одиночное выживание в исследовательской базе, социальная симуляция и один скрытый паразит.

**Статус:** независимое ядро социальных систем и первый игровой адаптер. Сборка и загрузка в конкретной версии Ports1de ещё не проверены.

## Идея

В большой базе живут 12 человек. Один из них — паразит, который может полностью перенять внешность, имя, социальную роль и воспоминания жертвы. Игрок управляет одним человеком напрямую, а остальные жители самостоятельно работают, общаются и строят отношения.

Игрок видит только то, что доступно его персонажу. События в других помещениях продолжаются, но не раскрываются в реальном времени.

## Важное о совместимости

Моды RimWorld для ПК не считаются автоматически совместимыми с Android-портом Ports1de. До реализации механик необходимо проверить конкретную сборку игры, загрузчик модов, Harmony и доступные API порта.

## Текущий этап

- Ядро симуляции, памяти, расследований, инцидентов и решений паразита покрыто smoke-тестами.
- Адаптер RimWorld 1.7 / .NET 10 содержит стартовую диагностику и Harmony self-patch probe.
- Probe проверяет вход в `Verse.Mod`, доступность Harmony и выполнение postfix на безопасном тестовом методе внутри собственной DLL мода.
- Этот self-patch не доказывает, что Harmony может патчить методы самой игры в Ports1de; отдельная проверка на игровом методе остаётся обязательной.
- Адаптер требует локальные игровые DLL и Harmony из установки; эти файлы не включаются в репозиторий.
- Сборка против DLL исследованной Beta 14, установка на Android и проверка логов ещё не выполнены.
- Подробности и ожидаемые диагностические сообщения: [Runtime Probe](docs/ports1de-beta14/RUNTIME-PROBE.md).
